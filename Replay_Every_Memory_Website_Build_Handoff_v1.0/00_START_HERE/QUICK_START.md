# Quick start

## To review the handoff

1. Open `../README.md`.
2. Open `../03_WIREFRAMES/prototype/index.html` in a browser.
3. Compare page structure with `../02_WEBSITE_COPY/FINAL_WEBSITE_COPY_v1.1.md`.
4. Review unresolved launch items in `../01_SOURCE_OF_TRUTH/OPEN_ITEMS.md`.

## To build with Codex

1. Unzip this package.
2. Place the package in or beside the target website repository.
3. Open a Codex task in the target repository.
4. Paste the complete prompt from `../07_CODEX_PROMPT/BUILD_WEBSITE_WITH_CODEX.md`.
5. Replace `<HANDOFF_PATH>` with this folder's path, or leave it unchanged if the folder is visible in the current workspace and uniquely named.

Codex should inspect the repository, preserve an existing supported stack, implement every required route and state, and run the acceptance and QA gates. The prompt does not authorize deployment or external service configuration.

## Before public launch

Resolve the launch gates in `../01_SOURCE_OF_TRUTH/OPEN_ITEMS.md`, especially domain, store/social destinations, trailer/demo, press downloads, provider-specific privacy language, real form delivery, analytics decision, hosting, and final legal/trademark presentation.
