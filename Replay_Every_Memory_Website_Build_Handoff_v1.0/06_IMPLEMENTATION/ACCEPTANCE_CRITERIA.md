# Production acceptance criteria

## Content and facts

- [ ] Studio name is Replay Every Memory everywhere.
- [ ] Tagline is exactly “Dreams with a start button.”
- [ ] The only public roster is James, Emily, Ramona, and Matilda with approved roles.
- [ ] *Trash Dash* is “in development” and “launching in 2026.”
- [ ] Platforms are Steam, App Store, and Google Play without invented links.
- [ ] RC1 is described as in beta testing, not as a downloadable public beta.
- [ ] Trailer, demo, and storefronts use honest coming-soon states.
- [ ] Primary CTA is Follow Development and resolves to a real destination.
- [ ] No Tier 2/Tier 3 spoilers appear in public output.
- [ ] No fictional roster or superseded studio identity appears in public output.
- [ ] No placeholder syntax or dummy links appear.

## Structure

- [ ] Every required route exists and has a unique title and `h1`.
- [ ] Homepage first viewport identifies studio, game, genre/promise, status, and action.
- [ ] Journal supports the approved editorial sequence and an honest empty state.
- [ ] Site can add a second game without a structural rewrite.
- [ ] Press downloads are descriptive or clearly coming soon.
- [ ] Contact has verified delivery or a working email fallback.
- [ ] 404 provides useful recovery.

## Accessibility

- [ ] WCAG 2.2 AA is the target; no unsupported conformance claim is published.
- [ ] Keyboard pass succeeds.
- [ ] Focus is visible and logical.
- [ ] Mobile menu manages focus, Escape, return, and scroll lock.
- [ ] Automated critical/serious accessibility issues are zero or documented with an approved exception.
- [ ] Contrast thresholds pass.
- [ ] Alt text/captions are meaningful and spoiler-safe.
- [ ] Reduced motion works.
- [ ] Reflow and zoom work without loss.

## Responsive and visual

- [ ] No horizontal overflow at required widths.
- [ ] Mobile layout is intentionally reordered where specified without breaking DOM/keyboard order.
- [ ] Logo is not distorted or illegible.
- [ ] Approved assets ship; reference-only assets do not.
- [ ] Character focal points survive responsive crops.
- [ ] Empty, loading, failure, and unavailable states use final copy.

## Engineering and launch

- [ ] Production build is clean.
- [ ] Lint, types, and tests pass.
- [ ] Internal links and assets resolve.
- [ ] No full internal story ships client-side.
- [ ] Analytics defaults to off and no unapproved trackers load.
- [ ] Privacy copy matches actual providers before public launch.
- [ ] No secrets or private information are exposed.
- [ ] Screenshots and QA evidence are included in the implementation handoff.
