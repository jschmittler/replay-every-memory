Recommended homepage architecture

Six sections, each with one job

Implementation roadmap

Content readiness before decoration

P0 · Before promotion

  1. Publish three real Journal posts or stop making Journal the main CTA.
  2. Create a credible hero/game-media asset and 16:9 trailer placeholder.
  3. Use the official game logo on the Trash Dash detail page.
  4. Ship a downloadable press kit and fact sheet.

P1 · Highest return

  1. Compress the homepage to six sections.
  2. Move game imagery into the first mobile viewport.
  3. Add people and practice to Studio.
  4. Add three visual gameplay modules.

P2 · Build the system

  1. Add Journal categories and optional email signup.
  2. Introduce restrained gameplay and character motion.
  3. Add dated news and store badges as infrastructure is ready.
Research conclusion

Replay Every Memory should feel like the doorway to a game world—not the explanation of one.

The brand system should remain. The next version should use less narrative repetition, more game evidence, a visible team, and destinations that are complete enough to reward every click.
